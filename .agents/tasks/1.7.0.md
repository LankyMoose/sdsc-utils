## Task 2 — Steam scan: validate extra paths + thread through `list_installed_games`

**File:** `src/games/steam.rs`

Add a public validation function:

```rust
/// Returns true if `path` is a valid Steam library folder —
/// i.e. it contains a `steamapps/` subdirectory with at least one `appmanifest_*.acf` file.
pub fn validate_steam_library_path(path: &std::path::Path) -> bool {
    let steamapps = path.join("steamapps");
    let Ok(entries) = std::fs::read_dir(&steamapps) else {
        return false;
    };
    entries.flatten().any(|e| {
        let name = e.file_name();
        let s = name.to_string_lossy();
        s.starts_with("appmanifest_") && s.ends_with(".acf")
    })
}
```

Change the signature of `list_installed_games` to accept extra paths:

```rust
pub fn list_installed_games(extra_paths: &[std::path::PathBuf]) -> Result<Vec<SteamGame>, String>
```

After the `library_folders()` call that builds `roots`, iterate `extra_paths` directly in `list_installed_games` (not inside `library_folders`): for each path, if `validate_steam_library_path` returns false, emit `app_log::warn(format!("steam: skipping invalid extra library path: {}", path.display()))` and skip; otherwise call `push_library_paths(&mut roots, std::iter::once(path.to_string_lossy().into_owned()))`.

**Call-site in `src/app/mod.rs`:** Update the `spawn_blocking` closure to capture `extra_paths: Vec<_> = self.session.prefs.extra_steam_paths.clone()` and pass `&extra_paths` to `list_installed_games`.

### 4b. Extend `build.rs`

Add `parse_changelog` and `write_changelog` functions, then call them from `main()`.

`parse_changelog(src: &str) -> Vec<(String, Vec<(String, Vec<String>)>)>`:
- Walk lines. A line starting with `## ` (two hashes + space) opens a new release; capture everything after `## ` as the version string.
- A line starting with `### ` opens a section within the current release; capture the section name.
- A line starting with `- ` or `* ` is a bullet item; strip the leading `- `/`* ` and trim whitespace.
- Everything else is ignored.
- Return `Vec<(version, Vec<(section_name, Vec<item_text>)>)>`.

`write_changelog(out_dir: &Path, releases: &[(String, Vec<(String, Vec<String>)>)])`:
- Write `changelog_generated.rs` to `out_dir` with this shape:
  ```rust
  // Auto-generated by build.rs from assets/CHANGELOG.md — do not edit.
  pub struct ChangelogSection { pub title: &'static str, pub items: &'static [&'static str] }
  pub struct ChangelogRelease { pub version: &'static str, pub sections: &'static [ChangelogSection] }
  pub static CHANGELOG: &[ChangelogRelease] = &[ ... ];
  ```
  Escape `"` as `\"` and `\` as `\\` in string literals.

In `main()`, add:
```rust
let changelog_src = fs::read_to_string("assets/CHANGELOG.md").unwrap_or_default();
let releases = parse_changelog(&changelog_src);
write_changelog(&out_dir, &releases);
println!("cargo:rerun-if-changed=assets/CHANGELOG.md");
```

**Tests for `parse_changelog` (inline `#[cfg(test)]` block at the bottom of `build.rs`):**
- Multiple releases parsed correctly.
- A release with only one section (e.g. only `### Fixed`) works.
- Empty input returns empty vec.
- A bullet with special characters (`"` and `\`) round-trips through write/include correctly (string escaping).
