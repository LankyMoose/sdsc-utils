# Start immersive mode

**Status:** do-not-regress. **When to read:** immersive cover, reopen chord, controllers dock. Index: [README.md](README.md).

Compact Start (768×600) can promote to a borderless primary-monitor cover. Pref `start_screen_always_immersive` opens immersive only and makes Circle/Escape close (no demote). When off, the reopen / promote chord is fixed **PS** (Guide) and toggles compact ↔ immersive; Circle/Escape demotes (`Back`). Successful launch while immersive closes Start so a topmost cover cannot sit above the game.

Promote/demote ceremony: ExitCompact blackout → HWND resize under veil → EnterImmersive immersive chrome under one full-bleed veil (ease-in-out lift, ~0.45s, frame-capped); demote ExitImmersive full-bleed veil → resize → EnterCompact (+ scroll selection into view). Never paint immersive chrome at the wrong HWND size. Enter splash: **cached** art paints opaque under the enter veil (so the new window atlas uploads during blackout — reopen/warm hit, no ambient flash); **uncached** waits, then ease-in-out ambient → splash after the veil (~0.45s, dim tracks opacity). Stage backdrop stack adds a soft rectangular edge vignette over atmosphere/splash only (under games strip / dock / footer). Title nav still skips ambient via cover-crossfade underlay. **No separate cold-load view.** Compact process-first open paints normal chrome immediately with **skeleton** Games rows while `steam_scan_pending`, then defers the live Steam refresh (`STEAM_SCAN_SETTLE_DELAY_MS`). Immersive process-first cold (`cold_load_active`) arms the enter veil on open (lift onto ambient + controllers dock + footer) with the **games strip hidden**; a bottom-right **chrome status rail** stacks background jobs (Preparing / Steam / future sources). New jobs slide in from the bottom; finished chips stay **Success** and shift upward. When every chip is Success, a short hold then **staggered slide-right** clears the rail (bottom-first). Art-ready marks Preparing success, fades the games list (`GAMES_LIST_FADE_MS`) with ambient→splash, and immediately kicks Steam so both can stack. Must not re-black the chrome. **Compact→immersive promote** matches that cold enter: ExitCompact pre-warms circular strip art; settle arms the veil onto ambient immediately with the games strip hidden until art sync (or 3s timeout); settle skips art gen bump when decode is already in flight / sync-ready; `SteamScanAfterSettle` defers across the promote ceremony. Compact titlebar still shows a single primary chip. Pad/keyboard nav locked while cold (Escape/Close still works). Boot seeds Steam metadata from `%APPDATA%/<pkg>/steam_library.json` when present. Immersive cache-miss kicks a live scan during cold so art can resolve; cache-hit shows Preparing then kicks Steam on art-ready (no `STEAM_SCAN_SETTLE_DELAY_MS` — that delay is compact-only). Live Steam scan/refresh runs for at least 2s (`STEAM_SCAN_MIN_MS`) so immersive BR / compact titlebar scan chrome stays readable. Status chips slide In (`CHROME_STATUS_IN_MS`) into a growing BR clip (compact: single primary in the header); Success holds on the rail until the batch is done, then ExitRight (`CHROME_STATUS_EXIT_MS`) with stagger (`CHROME_STATUS_STAGGER_MS`) after `CHROME_STATUS_SUCCESS_HOLD_MS` + `CHROME_STATUS_STEP_HOLD_MS`. Warm reopen keeps the solid enter veil + cached opaque snap. Art-hold timeout 3s. A UI stall cannot skip the start of the enter curve (32ms/frame cap). Immersive art uses a **single-flight** `start-art-worker` thread (latest-wins mailbox): UI posts one `ArtJob` per selection; at most one decode runs at a time. Pins ±10 around selection (circular when immersive, linear when compact); unpinned entries stay until per-tier LRU caps. Order: selected cover → selected hero/list → visible ±2 strip → prefetch ring. Events: `StartArtEvent` (`SelectedReady` / `NearReady` / `JobDone`). List/hero/backdrop peeks are live (no catalog rebuild on warm). Splash art keeps a **continuous ken-burns** pan/zoom (burn-in drift) while held; title changes use cover-crossfade (solid outgoing underlay at **frozen ken-burns scale** + incoming fade) so ambient never bleeds and the old splash does not zoom-snap. Controllers dock is a right-side floating capsule island (same glass as footer hints), vertically inset so it clears the footer; unified fixed-height rows wipe via `WidthReveal` (full dock width layout + scissor peek→expand). Immersive dock peek↔expand uses Left/Right (dpad, stick, arrow keys); compact carousel still uses L2/R2. Dock face hints omit Float scale so row height stays locked. Strip Up/Down gated while `strip_anim` is active. Game/controller lists are pad-only (no mouse press/hover); edit actions stay clickable. Disconnect membership uses the same hot-path silence drop + `ServiceMessage::Controllers` as compact (dock rows + composite toast).

**Same-press open→promote:** open and promote share the reopen chord. After `OpenStart`, a [`ChordReleaseGate`](../src/domain/gesture.rs) keeps the sticky hold latched until the chord is continuously absent for 64ms (longer than one HID wake / bounce). A one-sample gap does not clear the latch or disarm detectors. Shell `consume_reopen_gesture_chord` must not `reset` on Missing snapshot (client mode has no local HID snapshot). Duplicate `OpenStart` while Start is already visible re-arms the latch.

**Immersive idle / sleep:** while immersive (not during promote/demote ceremony), a shared activity stamp (mouse move/click/wheel, keyboard Start keys, non-resting pad) drives two overlay phases on top of chrome via `theme::immersive_dim` (ease-in-out ~0.45s, separate from enter/exit veils). Prefs (Settings → Start screen labels Idle/Sleep): `start_screen_inactive_secs` (default 30; steps 5s/15s/30s/1–3/5/10m), `start_screen_sleep_secs` (default 120; steps 1–3/5m then 5m gaps to 60m; always ≥ one sleep breakpoint ahead of idle), `start_screen_inactive_dim_percent` (default 50). After idle timeout → dim to that percent (**Idle**); after sleep timeout → full black (**Sleep**). Any activity targets **Active** (clear). Cursor hide (2s) shares the same activity stamp but stays independent. **Pad while Sleep / sleep-wake:** no nav/launch/dock/cancel/haptics/sounds — non-resting pad may only start wake; gating lifts after Active + dim transition complete, then `pad_nav.prepare_on_open(false)` so held controls must rest. Idle wake may still apply the press. Keyboard/mouse can wake; only pad is hard-gated. Pure helpers: [`src/ui/start/idle.rs`](../src/ui/start/idle.rs).

**Start settings (Options):** DualSense Options toggles an in-window Start Screen settings surface ([`src/ui/start/settings.rs`](../src/ui/start/settings.rs)). Compact: dim scrim + centered modal stacked over the full chrome. Immersive: full-height right `WidthReveal` drawer above stage/dock/footer (separate from the controllers dock); idle/sleep veil stays above the drawer. Prefs match Configure → Start Screen except **Enabled** (Configure-only). Pad: Up/Down focus rows, Left/Right nudge sliders (and toggles: left=off, right=on), Cross toggle/activate, Circle/Options close. Reopen / promote chord is not configurable (always PS). Overlay priority: settings → manual_add → replace_confirm → edit → dock collapse → demote/close. Main Start footer stays on browse controls (idle while settings owns press). **Hint press ownership:** only the active surface lights face/Options/reopen glyphs — `HintPressOwner` in [`view.rs`](../src/ui/start/view.rs). Options glyph is a regular-weight monospace `START` capsule sized to the face-ring idle diameter.

Cold-start art order: boot may seed Steam metadata from `steam_library.json`; live scan on `StartOpened` refreshes and rewrites the cache. When metadata is available, UI `request_start_art` pins ±10 and submits one worker job; selected **hero/list** first (strip paints immediately), then selected **backdrop** (`SelectedReady` arms splash), then ±2 strip heroes/list (`NearReady`), then near backdrops, then prefetch heroes before backdrops (`JobDone`). Newer selections replace the pending job (mailbox drain between paths); a superseded job is **kept** and run next (close→reopen must not drop the reopen job). Start close: bump gen + `cancel_jobs` (cache kept for reopen). **Process Exit blank slate:** drop Start row Handles + immersive session; `art_worker::shutdown` wipes caches (icons / shell extracts / SVG rasters / ambient+wgpu diag) **before and after** join (clear-epoch rejects late inserts); service Quit waits ~2.5s for shell Exit before kill. Grep: `ui-diag: process exit begin|complete`, `art worker shutdown begin|complete`. Stale `StartArtEvent` gens are ignored. Strip `hero_icon` live-peeks hero then list tiers each frame (no row snapshot).
