# Start immersive mode

**Status:** do-not-regress. **When to read:** immersive cover, reopen chord, controllers dock. Index: [README.md](README.md).

Compact Start (640×500) can promote to a borderless primary-monitor cover. Pref `start_screen_always_immersive` opens immersive only and makes Circle/Escape close (no demote). When off, the reopen chord toggles compact ↔ immersive; Circle/Escape demotes (`Back`). Successful launch while immersive closes Start so a topmost cover cannot sit above the game.

Promote/demote ceremony: ExitCompact blackout → HWND resize under veil → EnterImmersive immersive chrome under one full-bleed veil (ease-in-out lift, ~0.45s, frame-capped); demote ExitImmersive full-bleed veil → resize → EnterCompact (+ scroll selection into view). Never paint immersive chrome at the wrong HWND size. Enter splash: **cached** art paints opaque under the enter veil (so the new window atlas uploads during blackout — reopen/warm hit, no ambient flash); **uncached** waits, then ease-in-out ambient → splash after the veil (~0.45s, dim tracks opacity). Title nav still skips ambient via cover-crossfade underlay. Cold / promote enter keeps a **solid veil until splash + ±2 strip heroes are decoded** (`enter art hold` → `enter art sync ready`), then snaps splash opaque under the veil and lifts — matching first-launch idle Steam-scan pre-warm. Timeout 3s. A UI stall cannot skip the start of the enter curve (32ms/frame cap). Immersive art uses a **single-flight** `start-art-worker` thread (latest-wins mailbox): UI posts one `ArtJob` per selection; at most one decode runs at a time. Pins ±10 around selection (circular when immersive, linear when compact); unpinned entries stay until per-tier LRU caps. Order: selected cover → selected hero/list → visible ±2 strip → prefetch ring. Events: `StartArtEvent` (`SelectedReady` / `NearReady` / `JobDone`). List/hero/backdrop peeks are live (no catalog rebuild on warm). Splash art keeps a **continuous ken-burns** pan/zoom (burn-in drift) while held; title changes use cover-crossfade (solid outgoing underlay at **frozen ken-burns scale** + incoming fade) so ambient never bleeds and the old splash does not zoom-snap. Controllers dock is a right-side floating capsule island (same glass as footer hints), vertically inset so it clears the footer; unified fixed-height rows wipe via `WidthReveal` (full dock width layout + scissor peek→expand). Immersive dock peek↔expand uses Left/Right (dpad, stick, arrow keys); compact carousel still uses L2/R2. Dock face hints omit Float scale so row height stays locked. Strip Up/Down gated while `strip_anim` is active. Game/controller lists are pad-only (no mouse press/hover); edit actions stay clickable. Disconnect membership uses the same hot-path silence drop + `ServiceMessage::Controllers` as compact (dock rows + composite toast).

**Same-press open→promote:** open and promote share the reopen chord. After `OpenStart`, a [`ChordReleaseGate`](../src/domain/gesture.rs) keeps the sticky hold latched until the chord is continuously absent for 64ms (longer than one HID wake / bounce). A one-sample gap does not clear the latch or disarm detectors. Shell `consume_reopen_gesture_chord` must not `reset` on Missing snapshot (client mode has no local HID snapshot). Duplicate `OpenStart` while Start is already visible re-arms the latch.

**Immersive idle / sleep:** while immersive (not during promote/demote ceremony), a shared activity stamp (mouse move/click/wheel, keyboard Start keys, non-resting pad) drives two overlay phases on top of chrome via `theme::immersive_dim` (ease-in-out ~0.45s, separate from enter/exit veils). Prefs (Settings → Start screen labels Idle/Sleep): `start_screen_inactive_secs` (default 30; steps 5s/15s/30s/1–3/5/10m), `start_screen_sleep_secs` (default 120; steps 1–3/5m then 5m gaps to 60m; always ≥ one sleep breakpoint ahead of idle), `start_screen_inactive_dim_percent` (default 50). After idle timeout → dim to that percent (**Idle**); after sleep timeout → full black (**Sleep**). Any activity targets **Active** (clear). Cursor hide (2s) shares the same activity stamp but stays independent. **Pad while Sleep / sleep-wake:** no nav/launch/dock/cancel/haptics/sounds — non-resting pad may only start wake; gating lifts after Active + dim transition complete, then `pad_nav.prepare_on_open(false)` so held controls must rest. Idle wake may still apply the press. Keyboard/mouse can wake; only pad is hard-gated. Pure helpers: [`src/ui/start/idle.rs`](../src/ui/start/idle.rs).

Cold-start art order: Steam scan returns metadata only; UI `request_start_art` pins ±10 and submits one worker job; selected **hero/list** first (strip paints immediately), then selected **backdrop** (`SelectedReady` arms splash), then ±2 strip heroes/list (`NearReady`), then near backdrops, then prefetch heroes before backdrops (`JobDone`). Newer selections replace the pending job (mailbox drain between paths); a superseded job is **kept** and run next (close→reopen must not drop the reopen job). Start close: bump gen + `cancel_jobs` (cache kept for reopen). **Process Exit blank slate:** drop Start row Handles + immersive session; `art_worker::shutdown` wipes caches (icons / shell extracts / SVG rasters / ambient+wgpu diag) **before and after** join (clear-epoch rejects late inserts); service Quit waits ~2.5s for shell Exit before kill. Grep: `ui-diag: process exit begin|complete`, `art worker shutdown begin|complete`. Stale `StartArtEvent` gens are ignored. Strip `hero_icon` live-peeks hero then list tiers each frame (no row snapshot).
